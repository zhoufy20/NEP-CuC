# NEP-CuC

NEP-CuC is a transferable machine-learned interatomic potential for 
Cu-C systems based on the Neuroevolution Potential (NEP) framework.

The potential was developed to describe diverse Cu-C environments, including
bulk Cu, carbon structures, Cu-C interfaces, defects, and non-equilibrium
atomistic simulations.

## Files

- `nep.txt`  
  Trained NEP-CuC potential file for molecular dynamics simulations.

- `train.xyz`  
  Development dataset used for training the potential.

## Usage

NEP-CuC can be used with GPUMD.

Please refer to the GPUMD documentation for simulation setup.
